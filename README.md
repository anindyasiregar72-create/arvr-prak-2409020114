## Refleksi

### 1. Mengapa objek di depan kamera menggunakan Z negatif?
Pada A-Frame, kamera secara default menghadap ke arah
sumbu Z negatif. Oleh karena itu, objek yang diletakkan
pada nilai Z negatif biasanya terlihat di depan kamera.

### 2. Mengapa WebXR hanya aktif pada HTTPS atau localhost?
WebXR memerlukan secure context untuk mengakses fitur
XR pada browser. HTTPS dan localhost menyediakan
lingkungan yang memenuhi persyaratan keamanan tersebut
untuk penggunaan dan pengembangan WebXR.

### 3. Apa perbedaan WebXR Device API, three.js, dan A-Frame?
WebXR Device API menyediakan antarmuka untuk mengakses
perangkat dan pengalaman XR. Three.js merupakan library
JavaScript untuk membuat grafik 3D, sedangkan A-Frame
memudahkan pembuatan scene 3D menggunakan elemen HTML
dan memanfaatkan teknologi grafik 3D serta WebXR.
